# Media Downloader V3 — Windows x64

Execute MediaDownloader.exe. O pacote inclui Python, Qt, yt-dlp/EJS, Node,
FFmpeg e FFprobe; não depende de uma instalação Python no computador de destino.
Mantenha toda a pasta onedir, incluindo `_internal`.

O instalador instala para o usuário atual, sem exigir administrador.
Histórico, configurações, logs e cache ficam em:
%LOCALAPPDATA%\MediaDownloader

Downloads ficam na pasta escolhida. A desinstalação preserva esses dados.
Para apagar dados do aplicativo, feche-o e remova explicitamente a pasta de
dados do usuário; isso não apaga downloads salvos em outro local.

O ícone fornecido nesta compilação é TEMPORÁRIO. Nenhum arquivo oficial aprovado
foi entregue ao desenvolvimento até a geração deste pacote.

O pacote não possui assinatura digital de código. Windows pode mostrar o
editor como desconhecido. Consulte `_internal\licenses` para licenças,
proveniência e obrigações de redistribuição dos componentes.
